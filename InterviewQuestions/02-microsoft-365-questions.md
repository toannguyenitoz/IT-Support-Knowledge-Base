# Microsoft 365 Questions

## 1. A user cannot access Outlook. What do you check?

**Sample answer:**

I test Outlook on the web, check license assignment, account status, MFA, service health, Outlook profile, OST cache and Exchange mailbox status.

---

## 2. What is a shared mailbox?

**Sample answer:**

A shared mailbox allows multiple users to access a common mailbox without requiring a separate licensed user in many standard scenarios.

---

## 3. What is message trace used for?

**Sample answer:**

Message trace is used to investigate email delivery, confirm whether a message was delivered, failed, quarantined or delayed.

---

## 4. What is Exchange Online?

**Sample answer:**

Exchange Online is Microsoft's cloud-hosted email and calendaring service within Microsoft 365.

---

## 5. How do you check Microsoft 365 outages?

**Sample answer:**

Use Microsoft 365 Admin Center → Health → Service health.
