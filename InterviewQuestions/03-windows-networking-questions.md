# Windows and Networking Questions

## 1. What does DNS do?

**Sample answer:**

DNS translates names such as microsoft.com into IP addresses that computers can use to communicate.

---

## 2. What does DHCP do?

**Sample answer:**

DHCP automatically assigns IP address configuration to devices on a network.

---

## 3. How do you troubleshoot no internet access?

**Sample answer:**

Check physical/Wi-Fi connection, IP address, gateway, DNS, ping tests, browser test, VPN/proxy and network adapter status.

---

## 4. What is Group Policy?

**Sample answer:**

Group Policy centrally manages Windows user and computer settings in Active Directory environments.

---

## 5. What does ipconfig /all show?

**Sample answer:**

It shows IP configuration details including IP address, subnet mask, gateway, DNS servers, DHCP status and adapter information.
